Kort sagt: din logg stannar på enheten. Det enda som skickas är anonym användningsstatistik och feedback som du själv skriver

Sunny Sunflower är en app utan egen server. Allt appen håller koll på (sollogg, solrosens tillstånd, humör och anteckningar, vänlogg) sparas bara på din enhet och skickas inte till någon, inte ens till utvecklaren. Appen använder ingen reklam, ingen spårning och inga analysverktyg (SDK:er) från tredje part. Det enda som lämnar enheten är anonym användningsstatistik och felrapporter som inte kan kopplas till dig (punkt 4), samt feedback som du själv skickar via Inställningar → Skicka feedback (punkt 3).

1. Vad behörigheterna används till

BehörighetSyfteHantering av data
Kamera Uppskatta ljusstyrkan omkring dig för att känna av solljus automatiskt Använder bara metadata om exponering och ISO. Inga bilder eller videor sparas eller skickas.
Plats (endast vid användning) Räkna ut tider för soluppgång och solnedgång Används bara för beräkningar på enheten. Sparas inte och skickas inte.
Lokalt nätverk · Nearby Interaction Ansluta till vänner i närheten för ”Sola ihop” och visa avståndet Namnet på den andra enheten och hur många gånger ni har solat ihop sparas bara på din enhet. Det är kommunikation på nära håll som inte går via internet.
Notiser Notiser om solrosen och påminnelser Använder bara lokala notiser på enheten.

Alla behörigheter är frivilliga. Även om du nekar kan du använda grundfunktionerna, som att logga manuellt.

2. Vilka data som sparas

  • Sollogg (datum, tid, uppmätt ljusstyrka)
  • Solrosens tillstånd och batterinivå
  • Humöremojier och anteckningar som du lägger till
  • Enhetsnamn för vänner du har solat ihop med, antal möten och datum för senaste mötet
  • Appinställningar (dagsmål, notisinställningar m.m.)

Alla dessa data sparas i appens lagring i iOS (UserDefaults) och raderas när du tar bort appen. Du kan också radera allt via Inställningar → Återställ data i appen.

3. Skicka feedback

När du skickar feedback via Skicka feedback i appen skickas det du har skrivit (typ av feedback, meddelande, bifogade skärmbilder samt namn och e-postadress om du har angett dem för att få svar) till utvecklaren via Apples offentliga iCloud-databas (CloudKit), tillsammans med appversion, enhetsmodell, iOS-version och språkinställning. Det används bara för att svara dig och förbättra appen, aldrig för reklam eller spårning.

Om du inte skickar någon feedback skickas ingenting. För att skicka feedback måste du vara inloggad på iCloud, men du kan också mejla om du hellre vill det. Vill du att feedback du har skickat ska raderas kan du höra av dig till adressen nedan.

4. Anonym användningsstatistik och felrapporter

För att veta ungefär hur många som använder appen och för att kunna rätta fel skickar Sunny Sunflower följande anonyma statistik till Apples iCloud (CloudKit). Bara utvecklaren kan läsa den.

  • Ett slumpmässigt ID som skapas när appen installeras (kopplas inte till dig, enheten, ditt Apple-ID eller andra appar, och byts ut om du installerar om appen)
  • Appversion, iOS-version samt region- och språkinställningar
  • Hur många gånger och vilka dagar appen har öppnats, samt installationsdatum (antal dagar sedan installationen)
  • Diagnosrapporter när appen kraschar eller hänger sig (appversion, iOS-version, enhetsmodell och teknisk information om felet)

Namn, kontaktuppgifter, plats och det du loggar, som sollogg, humör, anteckningar och vänlogg, ingår inte. Statistiken skickas bara när enheten är inloggad på iCloud.

5. Delning med tredje part och överföring till andra länder

Vi delar ingenting med tredje part. Feedback som du själv skickar och den anonyma användningsstatistiken ovan lagras dock i Apples iCloud (CloudKit), och Apples servrar kan finnas i andra länder.

6. Barns integritet

Appen samlar inte in personuppgifter om barn. Du behöver inte ange namn eller e-postadress när du skickar feedback.

7. Ändringar i policyn

Ändringar i den här policyn meddelas på den här sidan. Vid viktiga ändringar (till exempel om vi börjar samla in data) berättar vi det även i appens uppdateringsinformation.
