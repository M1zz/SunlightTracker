這是什麼 App？

向陽小葵是一款 iOS App，透過相機的亮度偵測自動辨識並記錄你實際曬到的陽光。 曬得越多，電量就充得越滿，再用這份能量養大專屬於你的向日葵。 不過如果沒有好好照顧，向日葵可是會枯萎的喔。🌱

  • ☀️ 依環境亮度自動偵測並記錄陽光
  • 🌻 充飽電量，養大向日葵
  • 📅 用行事曆和統計回顧紀錄，也能寫下心情和備註
  • 👥 和朋友在附近一起曬太陽，花瓣會染上繽紛色彩
  • 📱 主畫面小工具、鎖定畫面即時動態、動態島

那隱私呢？

沒有伺服器 · 所有紀錄都只存在你的裝置裡

向陽小葵的紀錄不會傳送到外部，只有你主動傳送的意見回饋才會送到開發者手上。 詳細內容請參閱隱私權政策。
