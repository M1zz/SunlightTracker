햇빛바라기 (SunlightTracker)

홈 지원 · 문의
요약: 기록은 내 기기 안에만, 보내는 것은 직접 쓴 피드백뿐

햇빛바라기는 자체 서버가 없는 앱입니다. 앱이 다루는 모든 데이터(햇빛 기록, 해바라기 상태, 기분/메모, 친구 기록)는 사용자의 기기 안에만 저장되며, 개발자를 포함한 그 누구에게도 전송되지 않습니다. 광고, 추적, 분석 도구(SDK)도 사용하지 않습니다. 밖으로 나가는 것은 사용자가 설정 → 피드백 보내기로 직접 보낸 의견뿐입니다(아래 3항).

1. 기기 권한별 사용 목적

권한사용 목적데이터 처리
카메라 주변 밝기(조도) 추정으로 햇빛 자동 감지 노출/ISO 메타데이터만 사용. 사진·영상을 저장하거나 전송하지 않습니다.
위치 (사용 중에만) 일출/일몰 시간 계산 기기 내 계산에만 사용. 저장·전송하지 않습니다.
로컬 네트워크 · Nearby Interaction 근처 친구와 "함께 트래킹" 연결 및 거리 표시 상대 기기 이름과 함께한 횟수를 내 기기에만 저장합니다. 인터넷을 거치지 않는 근거리 통신입니다.
알림 해바라기 상태 알림, 리마인더 기기 내 로컬 알림만 사용합니다.

모든 권한은 선택 사항이며, 거부해도 수동 기록 등 기본 기능을 사용할 수 있습니다.

2. 저장되는 데이터

  • 햇빛 기록 (날짜, 시간, 조도 측정값)
  • 해바라기 상태 · 배터리 충전량
  • 사용자가 입력한 기분 이모지와 메모
  • 함께 트래킹한 친구의 기기 이름, 만난 횟수, 마지막 만남 날짜
  • 앱 설정 (목표 시간, 알림 설정 등)

위 데이터는 모두 iOS의 앱 저장소(UserDefaults)에 보관되며, 앱을 삭제하면 함께 삭제됩니다. 앱 안의 설정 → 데이터 초기화로도 전부 지울 수 있습니다.

3. 피드백 보내기

앱 안의 피드백 보내기로 의견을 보내면, 사용자가 적은 내용(의견 유형, 메시지, 첨부한 스크린샷, 회신용으로 남긴 이름·이메일)과 함께 앱 버전, 기기 종류, iOS 버전, 언어 설정이 Apple의 iCloud(CloudKit) 공용 데이터베이스를 거쳐 개발자에게 전달됩니다. 답변과 앱 개선에만 쓰며, 광고나 추적에는 쓰지 않습니다.

피드백을 보내지 않으면 아무것도 전송되지 않습니다. 보내려면 iCloud 로그인이 필요하며, 원하면 이메일로 보낼 수도 있습니다. 보낸 피드백의 삭제를 원하면 아래 문의처로 알려 주세요.

4. 제3자 제공 · 국외 이전

제3자에게 제공하지 않습니다. 다만 사용자가 직접 보낸 피드백은 Apple의 iCloud(CloudKit)에 보관되며, Apple의 서버가 국외에 있을 수 있습니다.

5. 아동의 개인정보

본 앱은 아동의 개인정보를 따로 수집하지 않습니다. 피드백을 보낼 때 이름·이메일은 적지 않아도 됩니다.

6. 방침 변경

방침이 변경되는 경우 이 페이지를 통해 공지합니다. 중요한 변경(데이터 수집 시작 등)이 있다면 앱 업데이트 노트에도 함께 안내합니다.
